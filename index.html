✏️ Corregir ubicaciones

Consulta la API oficial del Estado argentino (apis.datos.gob.ar) desde tu navegador y reubica cada dirección sobre su calle real. Tarda ~1 minuto. Después revisá y descargá el JSON.
Con el modo activo: arrastrá el pin al lugar correcto, o abrí el popup y pegá las coordenadas de Google Maps (clic derecho sobre el punto en Maps → copia "-32.9445, -60.6342"). Cada pin corregido queda marcado como verificado. Al terminar, descargá el JSON y subilo al repo.
